# Pare

应用标识：`app.pare.desktop`  
文档版本：2026-10-20

## 一句话

在本机把一批图片压小，或一次编码成 WebP、JPEG、PNG。体积下来，画面按选定的质量档保留。

## 名字

Pare 的意思是削掉多余的部分，把东西本身留下。用在这里就是削掉体积，留下画面。

窗口标题、安装包名称、关于页都用 Pare。仓库、包名和应用标识用 `pare`。

这个产品和 ImageOptim 不是同一个软件。ImageOptim 只在 Mac 上、按原格式覆盖优化。Pare 从它的压图方式里取引擎和默认策略，并加上跨平台安装包和指定格式导出。

## 为谁做

手上有一批本地图片，需要：

- 体积变小，便于上传、打包、放进网页
- 可以继续用原格式，也可以改成 WebP、JPEG 或 PNG
- 画面不能被压坏
- 图片不要上传到网上

## 第一版做什么

- Mac、Windows、Linux 桌面窗口
- 拖入文件或文件夹，批量处理
- 原图不改，结果写到新文件夹，并保持原来的目录结构
- 输出格式与原图相同：按引擎链优化，只有更小才采用新结果
- 输出格式不同：从原图只编码一次
- 输出格式：WebP、JPEG、PNG，或保持原格式
- 输入格式：JPEG、PNG、GIF、SVG
- 质量档：照片、界面、无损
- 处理过程不联网

## 第一版不做什么

- 不修改、不内嵌 ImageOptim.app
- 不做访达右键、系统分享菜单、AppleScript
- 不做账号、云同步、自动更新、使用统计
- 不输出 AVIF、JPEG XL
- 不把 GIF 动画抽成一张静图，除非用户明确选择「只用第一帧」
- 不保证优化后一定比原文件小。没有变小的文件会原样复制到输出目录，并标明「未变小」

## 平台

| 系统 | 第一版安装包 | 说明 |
|---|---|---|
| macOS 10.15 及以后 | Apple 芯片、Intel | 通用场景分开两个包或一个通用包，以构建结果为准 |
| Windows 10、Windows 11 | 64 位 | 使用系统里的 Edge WebView2 |
| Linux | x86_64 | 需要系统提供 WebKitGTK。界面只做拖放、列表和设置 |

Windows ARM 和 Linux ARM 等对应引擎二进制齐备后再发安装包，不放进第一版承诺。
